# Serv00账号检测（多账号版）

基于原 PingCheck 仓库独立开发，分支：`feature/serv00-multi-account`。

## 1.2.0 更新
- App 图标改为用户提供的彩色四向箭头与数据库图案。
- 检测前增加 DNS 解析和 TCP SSH 端口连通性测试。
- 失败时记录失败阶段、解析到的 IP、TCP 连接结果、异常类型、异常原文、原因链和关键调用位置。
- 账号卡片增加“详情”入口，可查看并复制完整诊断信息。
- 检测历史同时保存详细诊断，便于之后回看。
- 新增账号时默认填写用户已验证可连接的 `cache9.serv00.com`，仍可自行修改。

## 功能
- 多账号保存、编辑、删除。
- 单个账号检测和顺序批量检测。
- 使用 SSH 密码或粘贴的 SSH 私钥进行真实认证。
- 只有 SSH 用户认证完成才记录成功；Ping、端口开放或 SSH 握手均不算成功。
- 每个账号独立保存最近成功登录时间和最多30条检测历史。
- 最近成功登录达到75天后显示提醒，并通过每日后台任务发送通知。
- 密码、私钥和检测历史通过 Android Keystore 的 AES-GCM 密钥加密后保存在本机。
- 首次连接时固定服务器 SSH 主机密钥指纹；后续指纹变化会拒绝连接。
- 检测仅执行 SSH 认证，不运行 shell 命令。

## 服务器填写
例如：
- 用户名：你的 Serv00 用户名
- 服务器：`cache9.serv00.com`（请按你的实际服务器填写）
- SSH端口：22
- 认证：Serv00密码或SSH私钥

私钥登录时，将完整私钥内容粘贴到私钥框；如果私钥有口令，填写私钥口令。

## 错误详情
检测流程依次检查 DNS、TCP 端口和 SSH 认证：
- DNS 失败：显示域名解析异常。
- TCP 失败：显示目标 IP、端口以及连接拒绝/超时等系统异常。
- SSH 失败：显示 JSch 异常、原始错误、原因链和调用位置。
- 详情可从账号卡片的“详情”按钮查看并复制；检测历史也会保留诊断文本。

注意：Ping 使用 ICMP，SSH 使用 TCP。IP 能 Ping 通，不代表 TCP 22 端口开放或 SSH 服务正在监听。

## 安全说明
- 账号凭据不会上传到 GitHub 或任何第三方服务器。
- 首次连接采用 TOFU（首次使用时固定主机密钥）：第一次连接的服务器密钥会被本机记录，之后密钥发生变化会阻止认证。首次连接请确认服务器地址确实属于 Serv00。
- 频繁认证失败可能触发服务器端安全限制；应用提供批量间隔并限制短时间重复点击。
